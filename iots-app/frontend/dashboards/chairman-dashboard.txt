*CHAIR MAN DASHBOARD*
Create the Chairman Dashboard for the Internal Operations Tracking System.

The Chairman is a higher-level business authority.

This is an executive oversight dashboard, NOT an administration console.

Primary purpose:
Give the Chairman a fast, organization-wide understanding of operational health without requiring them to manage routine work.

Navigation should emphasize:

Overview
Operational Performance
Global Work
Escalations
People Overview
Analytics & Insights
Reports
Announcements
Audit Summary
Profile / Security

Top-level dashboard should show:

- organization operational health
- active work count
- completed work
- pending work
- overdue work
- critical escalations
- team/department performance
- workload distribution
- attendance/availability summary
- target achievement
- major operational exceptions
- recent management actions

Create an executive insight panel:
"Requires Attention"

Examples:
- overdue work
- repeated task reassignment
- unresolved blockers
- unusual attendance patterns
- declining performance trend
- high workload concentration

Create an "Organizational Pulse" analytical section with:
- task completion trend
- SLA/on-time trend
- workload trend
- attendance trend
- target achievement trend

Create a "Global Work Monitor" table:
Task
Owner
Team
Priority
Due Date
Status
Risk/Attention
Last Activity

Allow the Chairman to inspect work and intervene only where their authorization permits.

Make interventions visibly important and require confirmation.

Do NOT fill the Chairman dashboard with:
- routine password resets
- everyday task creation
- low-level user management
- technical diagnostics

The visual hierarchy should make the Chairman feel like an executive decision-maker looking at the organization's operational cockpit.
