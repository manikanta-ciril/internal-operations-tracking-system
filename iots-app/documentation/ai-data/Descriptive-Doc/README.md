## 🏛️ The 11 Core Organizational Roles

1. **Chairman:** Apex executive oversight, enterprise operational radar, critical escalations, and quarterly award sign-offs.
2. **Super Admin:** Master platform governance, RBAC policy, security compliance, and system data authority (co-equal with IT Analyst).
3. **Admin:** Structured user onboarding, office geofence perimeters, attendance audit, global task monitoring, and corporate announcements.
4. **IT System Analyst:** Technical health, API uptime, security diagnostics, authentication anomalies, and incident response (co-equal with Super Admin).
5. **General Manager (Ipsheeta):** Cross-departmental operations, Board governance, accounts & royalty tracking, legal compliance, and network expansion.
6. **Senior Manager:** Multi-team supervision, cross-team workload balancing, manager escalation review, and delivery SLA assurance.
7. **Lead Manager (Manasa):** Direct team operations, daily task assignment, live availability tracking, overdue interventions, and QA approvals.
8. **Executive:** Core operational work execution, progress logging, work notes, deliverable uploads, and blocker ticketing.
9. **Business Development Executive (BDE - Bhavani):** Membership expansion outreach, cold calling, RERA/Google database mining, and follow-up queue management.
10. **Social Media Manager (Harshitha):** Brand campaigns, content calendar scheduling, multi-platform publishing, and quarterly report proofreading.
11. **Graphic Designer:** Creative brief execution, version-controlled design drafts (`v1`, `v2`, `v3`), conference print collaterals, and research report formatting.

## ⚙️ Core System Guarantees

- **Unified Front Door:** A single corporate login portal for all employees. The platform inspects credentials and GPS location, tagging remote sessions transparently without alarming error screens.
- **Dynamic Multi-Role Switching:** Employees with dual responsibilities (e.g., managing operations while executing client calls) switch workspaces instantly without repeated sign-ins.
- **Active Overdue Accountability:** Overdue tasks demand active manager intervention (deadline extension, reassignment, or escalation). No task is ever lost to passive drift.
- **Indelible Audit Trail:** All critical decisions, status changes, and file uploads are preserved in an append-only, tamper-proof audit ledger.
- **Objective Meritocracy:** Monthly star performers and quarterly excellence awards are determined by verifiable delivery metrics, celebrating sustained consistency.
