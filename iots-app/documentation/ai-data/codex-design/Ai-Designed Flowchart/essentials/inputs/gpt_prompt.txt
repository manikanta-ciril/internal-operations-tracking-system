			Select Specific Task
			    ↓
			Review Current Status
			    ↓

			    ├── NO → Continue Monitoring
			    │
			    └── YES
			         ↓
			       Edit / Reassign / Cancel /

			Use business-friendly language.

			- force edit
			- hard delete
			- queue manipulation

			- Change Assignment

			------------------------------------------------------------
			9.2 TASK STATE / EXCEPTION HANDLING
			------------------------------------------------------------

			The task architecture must represent:

			Assigned
			Pending / In Progress
			Overdue
			Reassigned
			Completed

			Operational execution may additionally represent:

			Blocked
			Waiting for Review
			Under Review
			Changes Requested
			Issue Resolved
			Done / Closed

			IMPORTANT:

			Reassigned is a transition/event, not a terminal state.

			Overdue is an exception requiring intervention.

			Completed is the final business outcome after appropriate review/approval.
